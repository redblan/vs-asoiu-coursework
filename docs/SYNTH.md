# Синтез

`make synth` синтезирует `soc_top` в Yosys 0.33 под Xilinx 7-series (`synth_xilinx`, семейство Artix-7) с прошивкой `marquee` в ROM.

| Ресурс | Количество | Что это |
| --- | --- | --- |
| LUT (логика) | 1 021 | LUT1 9, LUT2 174, LUT3 120, LUT4 93, LUT5 142, LUT6 483 |
| LUT-RAM | 48 × RAM64M + 2 × RAM32M | распределённая память: ROM команд, RAM данных, регистровый файл |
| Block RAM | 1 × RAMB18E1 | Font ROM (384 × 8) |
| Триггеры | 1 106 | FDRE 1095, FDSE 11: регистры конвейера, кэш (16 × 21 бит), видео-буфер, очередь UART, счётчики |
| CARRY4 | 68 | цепочки переноса сумматоров и счётчиков |
| MUXF7 / MUXF8 | 57 / 18 | широкие мультиплексоры чтения памяти |

Для сравнения: у младшего Artix-7 XC7A35T 20 800 LUT и 41 600 триггеров, то есть SoC занимает около 5 % логики.

**Почему почти вся память в LUT-RAM, а не в Block RAM.** ROM команд, RAM и регистровый файл читаются комбинационно: адрес и данные в одном такте. Block RAM в 7-series читает только синхронно, поэтому Yosys отображает такую память на распределённую LUT-RAM. Чтобы перевести ROM в Block RAM, выборку пришлось бы разбить на две стадии.

**Fmax.** Yosys не делает временной анализ с задержками конкретной ПЛИС. Глубина логики после отображения на LUT6 (`abc -lut 6`, `ltp`) — 7 уровней на самом длинном комбинационном пути. Это стадия EX: forwarding-мультиплексор → сумматор АЛУ → сравнение → выбор адреса перехода. При типичных для Artix-7 0,5–1 нс на уровень вместе с разводкой это порядка 100 МГц, но точное значение даёт только Vivado (`report_timing_summary` после place & route).

Отчёты: `build/synth_stat.txt`, `build/synth_ltp.txt`, полный лог — `build/synth.log`.
