# Синтез

`make synth` синтезирует `soc_top` в Yosys 0.33 под Xilinx 7-series (`synth_xilinx`, семейство Artix-7) с прошивкой `marquee` в ROM.

| Ресурс | Количество | Что это |
| --- | --- | --- |
| LUT | 1 011 | LUT1 11, LUT2 172, LUT3 112, LUT4 93, LUT5 155, LUT6 468 |
| Триггеры | 1 440 | FDRE 1429, FDSE 11 |
| Block RAM | 2 × RAMB18E1 | ROM команд и RAM данных |
| LUT-RAM | 2 × RAM32M | очередь приёма UART |
| CARRY4 | 84 | цепочки переноса сумматоров и счётчиков |
| MUXF7 / MUXF8 | 77 / 24 | широкие мультиплексоры (Font ROM, кэш, видео-буфер) |

Для сравнения: у младшего Artix-7 XC7A35T 20 800 LUT и 41 600 триггеров, то есть SoC занимает около 5 % логики.

**Куда попала память** (из `build/synth.log`):

| Память | Отображение |
| --- | --- |
| ROM команд 1024 × 16 | Block RAM; выходной регистр IF/ID слит с блоком |
| RAM данных 256 × 16 | Block RAM |
| Очередь UART 16 × 8 | LUT-RAM |
| Font ROM 384 × 8 | логика на LUT и MUXF7/MUXF8 |
| Регистровый файл, кэш, видео-буфер | триггеры: у них есть сброс, а у видео-буфера ещё и параллельный выход всех 32 столбцов |

Больше всего триггеров дают два кадра видео-буфера (2 × 256), кэш (16 × 21) и счётчики отладки.

**Fmax.** Yosys не делает временной анализ с задержками конкретной ПЛИС. Глубина логики после отображения на LUT6 (`abc -lut 6`, `ltp`) — 7 уровней на самом длинном комбинационном пути. Точное значение частоты даёт только Vivado (`report_timing_summary` после place & route).

Отчёты: `build/synth_stat.txt`, `build/synth_ltp.txt`, полный лог — `build/synth.log`.
