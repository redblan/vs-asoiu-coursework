# Ассемблер

`tools/asm.py` — двухпроходный ассемблер на Python 3 без внешних зависимостей.

```bash
python3 tools/asm.py asm/marquee.asm -o build/marquee
```

| Выходной файл | Что внутри |
| --- | --- |
| `build/marquee.rom.hex` | машинный код, по слову в строке — для `$readmemh` (`+rom=`) |
| `build/marquee.ram.hex` | начальные данные RAM, 256 слов (`+ram=`) |
| `build/marquee.lst` | листинг: секция, адрес, слово, исходная строка; таблица меток |

## Как работает

1. **Проход 1.** Строки очищаются от комментариев (`;` и `//`, кроме кавычек), выделяются метки `имя:`. Каждая команда и директива получает адрес в своей секции. Размер известен заранее: у команд 1 слово, у `LI` 2, у `LBLT` 3, у `.string` столько, сколько символов. Константы `.equ` вычисляются сразу.
2. **Проход 2.** Все метки уже известны. Команды кодируются по формату (R, I, U, J), смещения переходов считаются как `метка − (адрес + 1)`, у каждой константы проверяется диапазон.

Ошибки печатаются с номером строки, код выхода 1. Например:

```
asm/isa_test.asm: строка 22: смещение перехода 100 вне диапазона -32..31
asm/marquee.asm: строка 41: метка «tape» уже определена
```

## Синтаксис

```asm
        .equ MMIO, 0xFF00          ; константа
        .data                      ; секция данных (RAM)
n:      .word 10, 0x20, 'A'        ; слова
msg:    .string "HI\n"             ; по символу в слово, без нуля в конце
buf:    .space 8                   ; 8 нулевых слов
        .org 0x20                  ; перейти к адресу в текущей секции

        .text                      ; секция кода (ROM)
start:  LUI  R5, hi(MMIO)          ; hi()/lo() — старший/младший байт
        LW   R1, n(R0)             ; imm(rs) — адрес rs + imm
        LW   R2, (R5)              ; то же, что 0(R5)
        LI   R3, MMIO + 2          ; выражения: + - * / ( )
loop:   BNE  R1, R0, loop
```

- Регистры: `R0`–`R7`. Регистр букв не различает: `r1` = `R1`.
- Числа: `10`, `0x1F`, `0b101`, символы `'A'`, `'\n'`.
- Метки и константы не различают регистр букв и делят одно пространство имён: метка `tape` и константа `TAPE` — конфликт.
- Список команд и псевдокоманд — [ISA.md](ISA.md).

## Особенность варианта: длинные переходы

Условный переход достаёт только на −32..+31 слово. В бегущей строке обработчик UART длиннее, поэтому в ассемблере есть псевдокоманды `LBEQ`, `LBNE`, `LBLT`. Они кодируют обратное условие, которое обходит `JMP`, а `JMP` достаёт до любого адреса ROM:

```asm
        LBNE R3, R4, fail     ->   BEQ R3, R4, +1
                                   JMP fail
```

## Cross-verification

`asm/fib_manual.rom.hex` составлен вручную, с разбором битовых полей в комментариях. `make crosscheck` убирает комментарии и сравнивает файл с выводом ассемблера для `asm/fib.asm`: они совпадают слово в слово. Обе версии затем проходят один и тот же тестбенч (`make test-rtl`).
